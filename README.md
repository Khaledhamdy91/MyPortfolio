# Khaled Hamdy — Portfolio

Personal information security and cybersecurity portfolio.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages ready

## Structure

- `index.html` — page content and sections
- `style.css` — responsive dark cybersecurity design
- `script.js` — navigation, project filtering, active links, and reveal animations

## Content status

The first version intentionally uses only details that are safe to present publicly. Exact work history, education, certifications, CV, and project details should be added only after verification.

## GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The expected site URL is:

`https://khaledhamdy91.github.io/MyPortfolio/`
